# Projeto Hipertrofia — versão web inicial

## O que inclui
- Registo de treinos, exercícios, cargas, séries/repetições e notas
- Histórico de treinos
- Peso e medidas corporais
- Registo simples de refeições, calorias e proteína
- Corrida, caminhada e Muay Thai
- Cronómetro de descanso
- Layout adaptado para celular

## Importante sobre os dados
Esta versão salva os dados no armazenamento local do navegador. O seletor de perfil é apenas uma separação local e NÃO é autenticação segura. Não use para dados sensíveis e não espere sincronização entre dispositivos. Para contas privadas reais e sincronização entre celulares, é necessário configurar um backend/autenticação (por exemplo, Supabase ou Firebase) e hospedar o app.

## Como testar no PC
Abra `index.html` no navegador. Para instalar como app/PWA no celular, o site precisa estar hospedado em HTTPS; abrir o arquivo local não habilita a instalação PWA completa.
